This is a copy of [gitlab.com/beaexpert](https://gitlab.com/beaexpert), where the projects are maintained. Every project here has the same name and content as there.

- **Libraries** for the beA.expert API: [Python](https://github.com/beaexpert/bea-api-python) (leading) · [PHP](https://github.com/beaexpert/bea-api-php) · [JavaScript](https://github.com/beaexpert/bea-api-javascript) · [C#](https://github.com/beaexpert/bea-api-c-sharp)
- **Examples** in Python: [scripts for send, draft, eEB](https://github.com/beaexpert/bea-api-python-examples) · [beA2email](https://github.com/beaexpert/bea2email) · [ELSTER API](https://github.com/beaexpert/elster-api) · [Akteneinsicht API](https://github.com/beaexpert/akteneinsicht-api) · [SIGNER API](https://github.com/beaexpert/signer-api)
- **Connectors**: [n8n](https://github.com/beaexpert/n8n-nodes-bea-expert) · [Odoo](https://github.com/beaexpert/bea-expert-api-for-odoo-crm) · [Zoho CRM](https://github.com/beaexpert/bea-expert-api-for-zoho-crm)

With the beA.expert API of [be next GmbH](https://bea.expert) you connect your own law-firm software to the **beA** (besonderes elektronisches Anwaltspostfach). You need an API subscription: [bea.expert/api](https://bea.expert/api/). Try it in the browser: [console.bea.expert](https://console.bea.expert/). The four libraries have the same version and the same functions; each release is tagged and carries the API documentation as PDF.

Our other product [LexITanon](https://lexitanon.com) pseudonymises and redacts legal documents on your own computer or server; a Python example is in [lexitanon](https://github.com/beaexpert/lexitanon).
